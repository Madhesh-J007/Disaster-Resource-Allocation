# Contributing to Secondary Disaster Chain Reaction System

Thank you for your interest in contributing to this Machine Learning PBL prototype!

## How to Contribute

1. **Fork the Repository**: Create your own copy of the repository on GitHub.
2. **Create a Feature Branch**:
   ```bash
   git checkout -b feature/your-feature-name
   ```
3. **Make Your Changes**: Ensure code follows clean PEP 8 guidelines for Python and standard ES6 React conventions.
4. **Test Locally**:
   - Run dataset generation: `python generate_data.py`
   - Run model training: `python train_models.py`
   - Test FastAPI backend: `python app.py`
   - Test React frontend: `npm run dev`
5. **Submit a Pull Request**: Push your branch to GitHub and open a Pull Request with a clear description of your changes.

## Development Guidelines

- Keep code modular and readable.
- Maintain transparent technical honesty (do not exaggerate synthetic dataset metrics).
- Do not commit `.venv`, `node_modules`, or temporary log files.
