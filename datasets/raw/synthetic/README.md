# Synthetic Disaster Chain Reaction Baseline Dataset

## Dataset Overview
- **Purpose**: Provides baseline Monte Carlo simulation records for secondary disaster cascade triggers (e.g. Earthquake -> Landslide -> Dam Breach -> Secondary Flooding).
- **Format**: Tabular CSV (`datasets/raw/synthetic/synthetic_cascades.csv`).
- **Use Case**: Development, integration testing, and validation of graph neural network & cascade simulation pipelines.
