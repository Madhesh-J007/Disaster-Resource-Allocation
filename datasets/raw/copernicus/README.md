# Copernicus Emergency Management Service (EMS)

## Dataset Overview
- **Source**: European Space Agency (ESA) / Copernicus Open Access Hub.
- **URL**: [https://emergency.copernicus.eu/](https://emergency.copernicus.eu/)
- **Spatial Coverage**: Global satellite disaster flood extent maps.
- **License**: Creative Commons Attribution 4.0 International (CC BY 4.0).

## Acquisition Method
Manual drop or baseline generator. Metadata catalog stored in `datasets/raw/copernicus/copernicus_metadata.json`.
